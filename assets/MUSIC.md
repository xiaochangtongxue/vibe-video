# 预算拍点的曲目

本仓库不附带音乐文件，下面这些曲目的音乐权利归原权利方。仓库只保留拍点和段落分析：你自己准备的音频与下面记录的 SHA-256 完全一致时，`new_project.py --audio <文件>` 会直接用 `assets/*.beats.json` 里预算好的拍点；不一致（哪怕是同一首歌的其他版本）就自动重新分析。

把音频按各节「文件」一栏的名字放进 `assets/`，就成了内置曲目：`new_project.py` 不带 `--audio` 时用 `we-never.mp3`，其他曲目用 `--audio $SKILL/assets/<文件>` 指定。

各节里的 `analyze.py` 命令记录的是拍点当初怎么生成的，路径指向原作者本地的音频。

    python3 scripts/analyze.py assets/ba-huiyi-man.mp3 --cache assets/ba-huiyi-man.rhythm.json --downbeat-phase 0 --out assets/ba-huiyi-man.beats.json

节奏特征：

- **只有 58.8 秒**，适合 1 分钟以内的视频。
- 4/4，112.0 BPM，一小节约 2.14 秒。
- 重拍相位 0，由原曲已确认的重拍映射而来，用户已用节拍器在慢版上试听确认；小节 0 是原曲小节 5。`downbeatConfidence` 为 null 是因为相位是手动指定的。
